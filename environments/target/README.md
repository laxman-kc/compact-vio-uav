# Target deployment environment

No Jetson SKU, JetPack, CUDA, TensorRT, ROS 2, PX4, power mode, or sensor stack is
selected yet. Those versions must be co-designed from the approved mission,
sensor, power, latency, memory, thermal, and interface envelope.

Target-specific serialized engines will be built and benchmarked on the selected
device. An A10-generated engine is never treated as a portable release artifact.
