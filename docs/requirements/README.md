# Requirements

This folder contains the normative project requirements and their traceability identifiers.

- [Project requirements](project-requirements.md) defines the `R-*` requirement IDs.
- [Requirements index](../requirements.md) explains ownership and links related protocol records.
- [Architecture decisions](../adr/README.md) record why major boundaries changed.

Requirements describe intended behavior. Dated observations and benchmark results belong in
[`reports/`](../../reports/README.md); permissions, provenance, and receipts belong in
[`governance/`](../../governance/README.md).
